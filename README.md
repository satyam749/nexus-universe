# NEXUS UNIVERSE — 3D Arcade Website

## चलाने का तरीका
1. ZIP फाइल को Extract करें।
2. `index.html` पर डबल-क्लिक करें। आधुनिक ब्राउज़र में वेबसाइट और गेम खुल जाएंगे।
3. इंटरनेट कनेक्शन होने पर Google Fonts लोड होंगे; गेम का मुख्य कोड किसी बाहरी गेम लाइब्रेरी पर निर्भर नहीं है।
4. गेम शुरू करें। कंप्यूटर पर WASD या Arrow Keys इस्तेमाल करें। मोबाइल पर गेम क्षेत्र के नीचे दिखने वाले टच बटन इस्तेमाल करें।
5. P या Escape दबाकर गेम रोक सकते हैं। सर्वश्रेष्ठ स्कोर उसी ब्राउज़र में सेव होता है।

## फाइलें
- `index.html` — वेबसाइट का ढाँचा और हिंदी सामग्री
- `style.css` — रिस्पॉन्सिव डिज़ाइन, एनिमेशन और मोबाइल लेआउट
- `game.js` — कैनवस गेम, नियंत्रण, स्कोर, टक्कर, ऊर्जा और लोकल रिकॉर्ड

## ध्यान दें
यह एक पूरा चलने योग्य शुरुआती प्रोजेक्ट है, लेकिन ऑनलाइन मल्टीप्लेयर, यूज़र अकाउंट, सर्वर/डेटाबेस और वास्तविक 3D WebGL अभी शामिल नहीं हैं। वर्तमान गेम Canvas पर 3D-जैसे दृश्य प्रभावों वाला 2D आर्केड गेम है। आगे इसे Three.js/WebGL और बैकएंड के साथ बढ़ाया जा सकता है।
